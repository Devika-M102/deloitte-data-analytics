# Task 1: Tableau Downtime Analysis

## Project Overview
Analyzed equipment telemetry data for Daikibo using Tableau to explore machine downtime across factories and device types.

## Objective
Identify factories and device types associated with the highest potential downtime and create an interactive dashboard for exploring downtime patterns.

## Tools Used
- Tableau
- Calculated fields
- Bar charts
- Interactive dashboards

## Methodology
- Created an `Unhealthy` calculated measure assigning 10 minutes of potential downtime to each unhealthy status.
- Built a bar chart showing downtime by factory.
- Built a second bar chart showing downtime by device type.
- Combined both charts in a dashboard and configured the factory chart to filter the device-type chart.

## Key Learning
Practiced calculated fields, visual analysis, dashboard creation, and interactive filtering in Tableau.
